# 📜 Scripts

A personal collection of scripts I've written, adapted, and tested for real-world use — primarily around self-hosted infrastructure, server setup, and homelab automation.

---

## Scripts

| Script | Description | OS |
|---|---|---|
| [`docker-install.sh`](./docker-install.sh) | Installs Docker Engine and the Compose plugin from Docker's official apt repository | Ubuntu |

---

## Usage

Clone the repo and make the script executable:

```bash
git clone https://github.com/YOUR_USERNAME/scripts.git
cd scripts
chmod +x script-name.sh
sudo ./script-name.sh
```

Each script is self-contained and includes inline comments. Check the top of any script for specific requirements or notes before running.
